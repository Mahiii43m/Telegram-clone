# Orbit Chat

A real-time messaging platform developed for the **Space Science and Geospatial Institute (SSGI)** — facilitating secure, efficient internal communication for Ethiopia's national space agency.

---

## About SSGI

The Space Science and Geospatial Institute (SSGI) is Ethiopia's national agency for space science and geospatial technology, established in 2022. SSGI leads national space and geospatial activities, provides satellite data, and supports sustainable development through research and technology transfer.

---

## Project Overview

Orbit Chat is a custom messaging solution designed to meet the unique communication needs of SSGI. It provides a secure, scalable, and user-friendly platform for internal collaboration.

---

## Features

- User authentication (Sign up / Sign in)
- One-on-one real-time messaging
- Group chat functionality
- Push notifications
- Modern, intuitive UI
- Message read receipts
- Online/offline status
- Secure data handling
